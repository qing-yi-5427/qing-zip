## 功能

- 毛玻璃界面、浅深色主题、目录树和多标签浏览。打开「视图 → 平铺视图」可列出当前目录及其子目录中的条目，同名文件显示各自路径。每个标签独立记住这项选择。文件列表支持按名称、大小、压缩后大小、类型和修改日期排序。
- ZIP / 7z 等格式压缩，ZIP / 7z / RAR 等格式解压；支持加密、分卷和完整性检查。
- 支持在标签页中打开内层压缩包，修改后逐层保存至外层。内外层密码分别处理；关闭未保存的内层标签会提示保存或放弃，外层被其他程序修改时保留工作副本。
- 从符合条件的 ZIP 或 `.7z.001` 分卷中选取文件时，程序首次校验全包，只暂存选中内容。同次运行中，符合条件的无密码 `.7z.001` 分卷可复用仍被程序保护的完整验证结果，加快重复选取；每次仍重新检查分卷集合、访问权限和包内目录，关闭标签或修改、取消后重新完整校验。分卷支持无加密的非固实 Copy，以及使用 LZMA 或 LZMA2 的固实和非固实 7z，包括符合条件的 AES 加密分卷。
- 7z 可选 ZSTD、Brotli、LZ4 等扩展压缩方法；高级设置提供字典大小、固实压缩与块上限、字长（PPMd 为模型阶数）和文件名加密。仅为支持这些参数的方法启用对应控件。
- 新建 ZIP、7z 和 SFX 时，可分别选择是否保存修改、创建和访问时间，以及是否将压缩包时间设为内容的最新修改时间；这些选择会自动记住。还可开启“保留来源访问时间”，无法完整保留时会列出文件及原因。
- 支持 Brotli、LZ4、LZ5、Lizard、ZSTD 单文件流格式的压缩与解压，也可浏览和提取 WASM、ROMFS、UFS 分区镜像，以及 ZealFS v1 直接镜像中的多级目录。
- 文件校验支持 SHA-2 / SHA-3、BLAKE3、xxHash 等算法，可选择文件夹递归校验，也可混合输入文件和文件夹；支持所选算法、空目录提示和取消任务。
- 文件分割与合并：支持连续编号分块和校验清单，取消或失败时保留源文件；没有清单的第三方分块不能判断末卷是否缺失。
- 工具箱提供 LZMA 引擎基准测试，可选择线程、字典和轮数，查看压缩/解压速度、评分及完整报告，支持取消。
- 工具箱的双位置文件管理支持本地复制和移动、复制或移动到压缩包、压缩包之间复制，以及将包内所选内容复制到本地。两侧密码与文件名编码独立设置，嵌套包修改可保存回外层。
- 双位置文件管理可新建文件夹和空文件，支持每侧的前进、后退目录历史和前台自动刷新；映射网络盘保持手动刷新。添加或移动到压缩包时，可记住“保留来源访问时间”的选择，操作提示在刷新后仍可查看。
- 移动到压缩包时，先完整验证更新后的压缩包及所添加内容，再删除核对无变化的来源。无法保留的附加数据、来源变化或事务不可用时，保留相应来源，并列出文件名称和原因；压缩包成功保存与来源是否全部移走分别显示。
- 本地复制保留主数据、附加数据流、扩展属性（EA）、时间和常规属性；支持分别保留数据流的 NTFS 压缩状态，以及稀疏文件的长度和空洞布局。目标无法精确保留时会报错。跨卷移动在完整核对来源与目标后，通过可用的 NTFS 文件事务删除来源；事务不可用或文件发生变化时保留来源并说明原因。合并已有文件夹时会合并普通子项，保留原目标文件夹信息；不同的文件夹附加数据流或 EA 不会覆盖合并，并显示“部分完成”。移动时，相应源文件夹及其附加数据仍保留。复制到新文件夹会完整保留这些数据。
- 双位置文件管理中，本地单选文件或文件夹后，可通过“更多 → 附加数据流”只读查看数据流名称、大小和分配大小，并刷新清单。
- 本地单选普通文件或文件夹后，可通过“更多 → 创建链接”新建硬链接、文件符号链接、目录符号链接、目录联接点或 WSL 链接；不覆盖同名项目，创建后刷新两侧相同位置。
- 链接创建位置须是普通本地路径，并要求 NTFS 文件事务可用。硬链接须在同一卷；硬链接和 Windows 符号链接目标须存在且可读，符号链接需要账户本来持有创建权限。目录联接点允许目标目录尚不存在；WSL 链接原样保存 Linux 目标路径供 WSL 使用，两者无需符号链接权限。
- 常见文本预览、图片缩略图与原图打开；支持多选和包内文件复制。
- 本地 EFS 加密文件和文件夹复制保留加密、授权证书、附加数据流和扩展属性，发布前完整核对。合并已有文件夹时保留目标的加密设置和附加信息，并提示未合并的来源信息。EFS 跨卷移动暂时保留来源及其子项并说明原因。
- 包内文件可通过右键“作为压缩包打开”，无需依赖文件后缀；属性页面显示 CRC、压缩方法、加密状态及所选内容的大小；压缩包属性按需显示实际格式、固实状态、卷数和偏移等信息。
- 包内文件可通过右键“外部编辑”交给记事本或指定编辑器，确认后逐层写回；未改动不重写，冲突时保留副本并可另存。
- 在“新建压缩文件”或“添加文件”对话框中，可从资源管理器拖入要打包的文件和文件夹。
- 添加文件的“更新方式”提供添加并替换、更新并添加、仅更新已有和同步所选范围。更新按修改时间与大小判断；同步删除需要单独确认，未选择范围保持不变。
- 解压偏好自动记忆：智能解压、成功后回收原包、打开目标文件夹、关闭窗口。
- 文件关联与资源管理器右键入口；ZIP 修复、密码管理和有限范围密码恢复。

## 使用

x64 版支持 Windows 10 2004（19041）及以上版本和 Windows 11。Windows 11 ARM64 设备请选择文件名含 `arm64` 的版本。桌面界面需要 Microsoft Edge WebView2 Runtime。

- **便携版**：完整解压 `qing-zip-版本-portable.zip`，运行 `qing-zip.exe`，保留同目录中的其他程序文件及 `runtime` 目录。
- **安装版**：运行 `qing-zip-版本-setup.exe`，默认安装到当前用户目录，无需管理员权限。
- `Ctrl+O` 打开，`Ctrl+N` 新建，`Ctrl+E` 解压，`Ctrl+T` 检查完整性，`Ctrl+Tab` 切换标签。
- 文件列表支持方向键、Home / End、Shift 连续选择、空格勾选、回车打开和 Shift+F10 右键菜单。
- 文件列表可选择显示列、调整列顺序与宽度，并记住设置；压缩包目录树和双位置文件管理的本地目录树均支持方向键展开、折叠和跳转，以及 Home / End 定位。
- 文件关联需在 Windows 默认应用设置中确认；Windows 11 的传统右键入口通常位于“显示更多选项”。便携目录移动后，请重新启用右键入口。
- 启用普通文件的右键压缩入口后，可在资源管理器中一次选取 1 至 128 个文件，放入同一个新建压缩包窗口。可执行文件路径、全部文件路径和参数合计最多 32,767 个 UTF-16 码元（含引号、空格和末尾空字符）。超出 Windows 命令行长度上限时，整组选取会报错，可减少文件数后重试。

文件在本机处理。修复只能恢复仍可校验的条目，密码恢复仅尝试指定候选；不保证所有格式、损坏文件或加密方式都能处理。自动回收仅对完整成功解压的已验证单卷格式生效。

拖出包内文件时保持按住鼠标，文件准备好后可交给资源管理器复制。在准备期间松开鼠标或按 Esc 可取消此次拖出。x64 发行版已在真实资源管理器窗口中验证同时拖出文件和文件夹。

外部编辑目前一次处理一个文件。请先在编辑器中保存，再在“编辑 → 外部编辑会话”确认写回或结束。结束后再修改文件不会自动写回；由于外部编辑器可能把文件交给其他窗口，结束会话后工作副本保留在 `%LOCALAPPDATA%\qing-zip\EditedFiles`，重启后可从“编辑 → 保留的编辑副本”定位或另存。该目录不随预览缓存清理。

## 构建

需要 Rust stable、Visual Studio C++ Build Tools、Python 3.10+，以及 NSIS 3.11+（构建安装版时使用）。运行完整测试还需要 Node.js。

```powershell
./scripts/build.ps1 -NsisPath "C:/path/to/NSIS/makensis.exe"
```

输出在 `dist/`。`obz-gui` 是 Tauri 界面，`obz-rs` 是归档核心和 `obz.exe` 命令行工具。第三方运行时随 `runtime/` 提供，构建缓存和研究资料不进入发行包。构建会校验运行时哈希，并生成独立的引擎源码包。
