# 优化路线

以 Windows 用户日常使用的 ZIP、7z、RAR 为先。工作台、智能解压、任务中心、密码本和嵌套编辑已有实现。产品取舍见[产品定位](PRODUCT_VISION.md)。

| 优先级 | 用户要完成的事 | 如何判断值得修改 |
| --- | --- | --- |
| 1 | 收到别人工具制作的压缩包能打开，自己发出的文件对方也能解压 | 用同一份普通归档在 qing-zip 和参考工具上操作，确认文件名、目录和内容差异；写出修复用独立工具读回 |
| 2 | 打开大列表、预览、压缩与解压时少等待 | 同机同设置与 7-Zip 比较三次中位数，优先改善等待最长的两项 |
| 3 | 遇到重名、占用、密码错误时能判断下一步 | 检查原包、已有目标文件和最终任务状态，确保用户知道哪些操作已完成 |

沿用现有 Fluent 界面与格式引擎。Windows 11 一级菜单已有可验证的原生组件，正式签名和安装版生命周期仍是交付条件。[Explorer 集成](../qing-shell/README.md) · [质量与限制](QUALITY_REPORT.md)
