# qing-zip 产品定位

qing-zip 面向每天在 Windows 上收发、浏览和整理压缩包的人。打开归档时能迅速找到文件，解压前能判断去向，结束后能直接找到结果。发生冲突、中断或密码错误时，用户能看清原包、已保存文件和可恢复内容的状态。

| 产品决策 | 验收方式 |
| --- | --- |
| 优先做好 ZIP、7z、RAR/RAR5、TAR、GZIP、BZ2 和 XZ。保留其他已支持格式。 | 用普通、加密、分卷及固实样本检验实际支持的操作。按格式区分读取、创建和更新能力。引擎变更同时核对来源、许可和互读结果。 |
| 让创建和解压的常用操作容易完成。格式、级别、密码、输出位置应易于发现，适用的专业参数仍可展开。 | 新用户能凭默认值完成一次操作，专业用户能控制字典、线程及固实设置。冲突、回收原包和写回嵌套归档必须与用户的实际选择一致。 |
| 任务以文件结果为准。 | 只有可测的阶段才显示进度和预计时间。重试应保留已确认的结果，完成、取消、部分完成各自显示实际文件位置。 |
| Windows 11 窗口和短时浮层有清晰的视觉层级。 | 检查真实 Tauri/WebView2 应用的浅色、深色、键盘焦点、纯色回退、系统高对比度和减少动画。材质、文字对比和间距按现有[界面设计规则](UI_DESIGN_SYSTEM.md)维护。 |
| 稳定性、速度和可读性一同验收。 | 改动前后使用相同输入、架构和配置。检查完整性、等待时间分布和额外资源消耗。说明首次启动、缓存状态以及仍不能量化的影响。 |

默认保持本地处理。对单个失败分支，优先给出用户能完成的下一步，例如输入密码、选择另一个输出位置或打开恢复目录。回收原包沿用成功验证、来源身份及分卷限制。[深度解压与恢复](deep-extraction.md)
