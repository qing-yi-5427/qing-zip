# 性能基线

下表保留已测安装版的参考值，供定位明显回退。Windows 11 x64 build 26300，产品提交 `be86c35`。每档预热一次，保留系统文件缓存，使用新的进程和输出目录测五次，校验输出的目录和 SHA-256。[历史测量及波动范围](https://github.com/qing-yi-5427/qing-zip/pull/70)

| 普通 ZIP 操作 | 中位数 |
| --- | ---: |
| 创建 32 MiB、4 个文件 | 126.23 MiB/s |
| 解压同一组文件 | 336.58 MiB/s |
| 解压深层目录树样本 | 1.09 秒 |

[已安装 ZIP 测量脚本](../scripts/measure-installed-zip.py)记录端到端耗时与进程树资源。比较两个版本的大型 ZIP 追加可使用[追加基准](../scripts/measure-large-zip-add.py)。

与 7-Zip 的日常对照使用同一台机器、同一份文件与压缩设置，每组测三次，记录中位数、范围和缓存条件。分别测约十万项归档打开、1 GB 混合文件解压、数万小文件创建，以及双击包内文件到预览可见。把时间和对应版本放在修复 PR 中；上表的单产品数据不能用于推断这四项的相对速度。
