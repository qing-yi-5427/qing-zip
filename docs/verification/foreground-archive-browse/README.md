# 真实前台窗口首次选中与大 ZIP 浏览

使用主线 `ba6a5e9`、`14b9e2a` 的 Windows x64 便携包在同一台托管 Windows Server 2025（26100）上交替运行，CPU 为 AMD EPYC 7763 64-Core Processor，内存 16 GiB，WebView2 157，100% 缩放。每个规模先预热一对，再按交替顺序测五对。每轮启动新进程，使用预热后的独立本地配置。每次均确认操作系统前台窗口属于测量进程、WebView 报告对应的实际程序路径，随后点击第一行复选框并观察到该行变为选中。计时从启动进程前到自动化观察到该状态，包含窗口连接和采样延迟。系统与存储缓存未清空。

| 条目数 | 启动至观察到的状态 | 基线中位 | 当前主线中位 | 同轮差值中位（范围） |
| ---: | --- | ---: | ---: | ---: |
| 10,000 | 首行可见 | 860.2 ms | 835.2 ms | −28.4 ms（−124.7 至 +13.4） |
| 10,000 | 首行已选中 | 879.0 ms | 852.6 ms | −26.4 ms（−128.8 至 +12.5） |
| 50,000 | 首行可见 | 1,272.2 ms | 1,266.1 ms | +1.7 ms（−50.8 至 +50.0） |
| 50,000 | 首行已选中 | 1,306.9 ms | 1,304.4 ms | +1.9 ms（−39.8 至 +47.3） |

两组到首次选中的配对差值均跨零，本样本无法确定两版有稳定快慢关系。50,000 条目时，当前主线打开宽目录、目录内搜索、全包搜索、排序和滚动的中位用时分别为 60.3、67.9、61.3、25.7 和 55.3 ms。每个检查点均核对前台状态、结果条目和视口。每轮后复查原包 SHA-256，24 个会话均正常退出且已恢复测试设置。真正的冷盘启动、物理屏幕呈现和不同用户机器仍需单独验证。
