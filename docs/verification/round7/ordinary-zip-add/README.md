## 大包普通新增的实际等待时间

在 10,000 和 50,000 个小文件的普通 ZIP 各加入 3,328 字节。每种规模预热后交替五对，保留系统缓存。计时从 CLI 进程启动到成功退出，随后独立读回所有成员。每一对成品 SHA-256 相同。

| 旧包条目 | 基线中位 | 候选中位 | 配对差中位（范围） |
| --- | ---: | ---: | ---: |
| 10,000 | 451.2 ms | 465.0 ms | +13.8 ms（−0.3 至 +31.0） |
| 50,000 | 2,878.5 ms | 2,920.6 ms | +44.5 ms（−31.8 至 +71.5） |

两个规模的候选中位较慢，逐对差值均有波动。该测量用于估计中断保护的代价。磁盘冷缓存及不同机器的耗时仍待对照。[逐轮数据](large-add-timing.json) · [测量脚本](measure-large-zip-add.py)
