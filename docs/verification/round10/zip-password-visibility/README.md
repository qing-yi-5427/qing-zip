# ZIP 创建时的密码说明

旧版创建表单在展开 ZIP 密码区后只显示密码输入、加密算法和显示密码复选框。独立 7-Zip 26.00 实际读取旧版从窗口创建的样本，确认 AES-256 ZIP 无密码仍可看到文件名，而启用文件名加密的 7z 隐藏文件名。对两种格式，错密码和无密码都未写出非空内容，正确密码只解出与来源 SHA-256 一致的文件。[加密成品与独立读回](https://github.com/qing-yi-5427/qing-zip/pull/68)

#69 在 ZIP 密码区增加「ZIP 密码保护文件内容，文件名仍可见。」这行说明。最终候选将说明移到密码输入框前，用户展开密码区即能读到。真实归档内容的对照由 #68 单独覆盖。[实现及前端回归](https://github.com/qing-yi-5427/qing-zip/pull/69)

第一版候选 `e74ec00` 放在密码控件底部的说明，在 780 × 750 CSS 像素窄窗自然展开、滚动位置为 0 时只露出文本矩形的 23.96%。手动滚到说明后可读，但自然展开未通过。[初版裁切截图](initial-candidate-narrow-dark-clipping.png) · [初版自然展开测量](initial-natural-viewport.json)

## 界面响应

真实 WebView2，计时视口为 1120 × 820 CSS 像素，DPR 1.5。每版各预热一个进程，随后交替运行七对新进程并保留系统缓存。启动耗时从启动请求算至主页就绪，含调试连接和检测。表单及密码区耗时从 DOM 点击事件开始，待目标控件占有布局并经过两次动画帧回调。两个点击在每进程各做三次，先取该进程中位数，再比较七对。该采样范围不涵盖系统冷启动或屏幕呈现时刻。

| 计时项目，ms | 安装版中位（范围） | 候选中位（范围） | 逐对差中位（范围） |
| --- | ---: | ---: | ---: |
| 启动至主页就绪 | 525.09（515.84–568.33） | 533.76（516.75–558.92） | +17.92（−51.58 至 +34.82） |
| 打开创建表单 | 13.40（12.80–13.90） | 12.80（12.50–13.20） | −0.30（−1.10 至 −0.20） |
| 展开密码区 | 12.90（12.40–13.50） | 12.60（12.00–13.60） | −0.10（−0.90 至 +0.70） |

启动和展开密码区的逐对差范围跨零。打开表单在七对中均快 0.2–1.1 ms，变化小于该测量中的一帧。原始收据包含各对实际次序、启动时长、每次点击原值、视口、控件位置及程序退出码。[脱敏原始收据](receipt.json)

复核时从首页打开「新建压缩包」，展开「设置密码」，保持初始滚动位置，分别在两种主题下检查全文与操作按钮。再切换 7z、ZIPX、SFX、TAR，最后切回 ZIP 并展开密码区。此次截图与计时范围为 Windows 11 x64 实测。真实 200% 缩放、读屏、高对比与其他架构未测。
