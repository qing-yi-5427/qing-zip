# 0.12.23 质量报告

2026-11-23 以本地提交 `0cc51aa` 建立基线。复测使用独立工作树、便携构建以及临时数据。以下优先级依据用户能观察到的结果。一个样本通过，只计入该样本覆盖的格式、行为与平台。

## 强退后仍在读包的校验进程

旧版退出后，外部校验仍会读取原包。约 71.5 MB 的普通 ZIP 上，三轮额外使用了 219–234 ms CPU。修复覆盖主动测试归档、ZIP 编辑后的校验和选取提取 TAR 时的预检。对匹配的校验进程执行强退回归后，源归档完整，正常重试成功。[校验进程回执](verification/round8/verifier-lifetime/README.md)

## ZIP 写完后被中断

普通 ZIP 的新中央目录已可读取、原名尚未替换时强退，安装版三轮都保住原包并成功重试，每轮仍留有约 1.49 MiB 完整候选。进入提交后，在两个确定的检查点强退，原名空闲时可还原原包，原名被其他文件占用时保留该文件和原包。写入中、写完后及原名替换期间需分别验收。[实测与回收缺口](verification/round8/zip-commit/README.md)

## 主线安装版的 ZIP 中断与解压反馈
