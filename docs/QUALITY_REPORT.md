# 质量与已知限制

| 用户操作 | 已确认的行为与范围 |
| --- | --- |
| 解压经典 RAR 分卷 | 从首卷打开的普通 Store 三卷样本已修复，校验与解压结果和 UnRAR 一致。[回归样本](../obz-rs/tests/fixtures/deep/rar15) |
| 用密码创建 ZIP | AES 加密文件内容，文件名仍可被列出。需要隐藏文件名时可选 7z 和文件名加密。[创建窗口说明](https://github.com/qing-yi-5427/qing-zip/pull/69) |
| 在批量解压中继续未完成项目 | 已开始而结果未确认的项目保留原目标供检查，用户可继续未开始的项目。替换已有目标仍需确认。[使用说明](../README.md) |
| 修改嵌套压缩包后另存 | 已登记的普通 ZIP 内层编辑可在重启后从保留的副本另存。退出前尚未登记或临时文件已被系统清理时无法恢复。[使用说明](../README.md) |
| 通过 Windows 11 一级菜单调用 | 已用临时签名在托管 Explorer 验证三项操作。正式签名及安装版注册、升级、卸载仍待验收。[适用范围](../qing-shell/README.md) |
